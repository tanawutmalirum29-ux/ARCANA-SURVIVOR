# Seasons Year One — Content Calendar & Pass Design

**Planning calendar only.** วันเปิด Season 1 เริ่มเมื่อ commercial gate ผ่าน; สัปดาห์ในเอกสารนี้เป็นสัปดาห์สัมพัทธ์ ไม่ใช่วันประกาศเปิดจริง

## 1. Season cadence
- 1 season = 12 weeks (4 Acts x 3 weeks); อีก 1–2 weeks เผื่อ QA/transition ได้หากทีมเล็ก
- Season XP จากจบรอบ + daily/weekly/season missions; 50 reward levels
- Free Track ทุกคนมี, Premium Track ซื้อสมัครใจเฉพาะสกิน/พื้นหลัง/profile/victory; **ไม่เพิ่ม stats**, ไม่จำกัดด่าน
- Late join catch-up quests, weekly XP buffer, rerun/archives เพื่อไม่ต้องเล่นทุกวัน
- ก่อนเปิดซีซันให้ QA ทดลองผู้เล่น casual (3 sessions/week) ควรเก็บ free featured skin ได้; ผู้เล่น active สามารถจบ track โดยไม่ต้องซื้อ boost
- ตอนซีซันจบ: claim grace window, snapshot entitlements, แจ้งการหมดอายุ, สกินที่ได้เป็นเจ้าของถาวร; premium track ซื้อแล้วแต่ยังไม่ claim ให้ใช้กฎที่แจ้งชัดและเป็นธรรม

## 3. Template: per-season 12-week schedule
| Week | Gameplay / live content | Rewards cadence |
|---|---|---|
| W01 | เปิด season, Act 1, tutorial catch-up, shop catalog | Free starter cosmetics + pass tiers 1–5 |
| W02 | Weekly Trials + Event A starts | event currency shop |
| W03 | Event A finale + Act 1 boss | event free skin |
| W04 | Act 2, story chapter, map modifier | free frame / pass |
| W05 | Event B starts (Boss Hunt) | boss currency / aura |
| W06 | Boss Hunt finale + mid-season QA/economy review | achievement-only cosmetic |
| W07 | Act 3 + limited alternate map | free cosmetic recolor |
| W08 | Event C starts (challenge ladder) | trail / emote |
| W09 | Event C finale + community goal | community free unlock |
| W10 | Act 4 + season finale boss | high-tier free aspirational reward |
| W11 | Catch-up week + archive preview | pass XP bonus through gameplay (not bought power) |
| W12 | Finale, pass claim reminders, announcement next season | free commemorative item / grace |

Events ในตารางเป็น campaign slots; weekly/daily evergreen events ยังทำงานต่อเนื่อง

## 4. Each season production package (target, scaled to team capacity)
- 1 season key art, 1 biome palette / 1 boss modifier or new boss only if budget allows
- 1 story arc split 4 chapters, 3 themed biweekly events, 1 recurring boss rotation, 1 community objective
- 6–10 cosmetic items across tiers: อย่างน้อย 2 free gameplay, 1 free high tier, 1 achievements, 1 event shop, 2–3 premium optional, cosmetic extras
- 50 pass tiers can be currency, cosmetics, emotes, frames, trails; ไม่ต้องสร้าง 50 full costumes
- Event art, UI thumbnail, localized copy, return policy, announcement assets & QA checklist

## 5. Season operations & creative lock
S-8w concept & event themes -> S-6w gameplay/reward budgets -> S-5w art approval -> S-4w prototype & economy simulation -> S-3w content freeze -> S-2w staging QA -> S-1w announce -> S0 launch -> S+6w mid-review -> S+12w transition.
- ภาระการผลิตลดได้: reuse biome with palette changes; rerun older events transparently; never promise unbuilt cosmetics
- Season pass ต้องมี contingency: server down -> extend season/compensate; paid grant bug -> purchase hold, reconciliation, public update
- Localization TH first / EN optional after quality review
