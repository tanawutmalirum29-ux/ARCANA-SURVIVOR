# Arcana campaign and lobby

คู่มือระบบล็อบบี้และความก้าวหน้าในเครื่องสำหรับงาน #61 บนฐาน `efeb314c7e706a3a70d7a3ba209592b673ffc88c` ภาพรวมใช้แนวทางเกม action roguelite แต่เนื้อหา ชื่อ และภาพวาดเป็นของ Arcana เอง

## เล่นอย่างไร

1. แท็บ **ผจญภัย** เลือกบทและโหมด กดเริ่ม เดินด้วย WASD / ลูกศร หรือแตะลากบนสนาม ตัวละครยิงอัตโนมัติขณะเคลื่อนที่
2. เมื่อเลเวลขึ้น เลือกหนึ่งพรเวท Pause หยุดเวลาได้ เมื่อกลับล็อบบี้สามารถกลับมารอบเดิมได้
3. จบรอบแล้วรับ Gold วัตถุดิบ อุปกรณ์ และชิ้นส่วนตามผลการเล่น ระบบแสดงรางวัลหลังบันทึกสำเร็จ
4. แท็บ **ตัวละคร** จัดชุดและพัฒนาฮีโร่ แท็บ **เติบโต** พัฒนาระบบถาวร แท็บ **กิจกรรม** รับภารกิจและบันทึกดาราฟรี
5. ไม่มีค่าพลังงานขวางการเล่น โหมดต่าง ๆ ปลดล็อกตามการเล่นและการผ่านบท

## เซฟและรอบค้าง

- IndexedDB `arcana-campaign-v2` เป็นที่เก็บข้อมูลหลัก มี Gold กระเป๋าเดียวที่ `profile.gold`
- นำเข้าข้อมูล v1 เดิมครั้งเดียว รักษา Gold สกิน สถิติและการตั้งค่า พร้อมให้ชุดเริ่มต้นครั้งเดียว ไม่เขียนทับข้อมูล v1
- หากเซฟอ่านไม่ได้ เสียหาย หรือเป็นเวอร์ชันอนาคต ระบบหยุดการเขียนและแสดงให้ลองใหม่ ไม่เริ่มใหม่แทนข้อมูลที่อ่านไม่ได้
- ทุกการหัก/เพิ่มวัตถุดิบ สิ่งของและเครื่องหมายรับรางวัล อยู่ใน IndexedDB transaction เดียว ป้องกันยอดหายเมื่อทำงานพร้อมกันหลายแท็บ
- หน้าจอแก้ข้อมูลหลัง commit สำเร็จเท่านั้น หากแท็บอื่นเปลี่ยนข้อมูล จะโหลดข้อมูลใหม่และให้ผู้เล่นตรวจอีกครั้ง
- ตอนเริ่มรอบ เก็บ seed และชุดค่าพลังไว้ตายตัว การเปลี่ยนอุปกรณ์ภายหลังไม่เปลี่ยนรอบที่เริ่มแล้ว
- ถ้าปิดหรือโหลดหน้าใหม่ สามารถเริ่มรอบค้างจากต้นรอบด้วย seed/ชุดเดิมได้ **ยังไม่มี checkpoint ตำแหน่งกลางการต่อสู้**
- การรับรางวัลซ้ำจากรอบเดิมให้ผลเพียงครั้งเดียว การบันทึกล้มเหลวสามารถลองซ้ำได้
- ภารกิจรายวัน/สัปดาห์ใช้วัน UTC ที่เริ่มรอบล่าสุด เริ่มรอบใหม่จึงเปลี่ยนช่วงเวลา ทำให้รางวัลค้างยังรับได้ก่อนเริ่มรอบในวันใหม่
- ข้อมูลอยู่ในเบราว์เซอร์นี้ การล้างข้อมูลเว็บไซต์ทำให้เซฟหาย และข้อมูลในเครื่องไม่ใช่หลักฐานสำหรับอันดับหรือการซื้อออนไลน์

## โครงสร้างโค้ด

| ตำแหน่ง | หน้าที่ |
|---|---|
| `src/progression/` | แค็ตตาล็อก schema validation คำสั่งและสูตรค่าพลังแบบ pure |
| `src/campaignStore.js` | นำเข้า legacy และ transaction ที่เก็บ/แก้เซฟ |
| `src/campaignClient.js` | เรียงคำสั่งจากหน้าจอ ตรวจ revision แสดงเฉพาะค่าที่บันทึกแล้ว |
| `src/ui/` + `src/lobby.css` | ล็อบบี้ responsive รายการ Modal ค่าใช้จ่ายและข้อความล็อก |
| `src/gameplay/` + `src/engine.js` | จำลองสนามแบบ seeded และผลจริงของอุปกรณ์/โหมด/ตัวช่วย |
| `src/main.js` + `src/render.js` | เชื่อม state ของหน้าเกม การควบคุม เสียงและภาพ |
| `src/progression/CONTRACT.md` | สัญญาคำสั่ง state และ runConfig แบบละเอียด |

โมดูล economy/events เดิมเก็บไว้รองรับการทดสอบและการพัฒนาเดิม **ไม่ได้เป็นกระเป๋าที่สองในเกม** runtime ใช้คำสั่ง progression กับ campaignStore เป็นทางเขียนข้อมูลเดียว

## สิ่งที่ยังไม่เปิด

บัญชีและ cloud save, clan/co-op, leaderboard สาธารณะ, การซื้อเงินจริงและสิทธิ์ premium ต้องมีบริการฝั่งเซิร์ฟเวอร์และผ่าน security/release gate ก่อนเปิด ไม่จำลองข้อมูลผู้เล่นออนไลน์หรือผลการชำระเงินให้เหมือนใช้งานจริง

Chromium/WebKit ใน CI เป็น browser automation ไม่ใช่หลักฐานทดสอบบน iPhone/Android จริงหรือการรับรอง FPS/สมดุลเกมระยะยาว
